1. Summary

BetterClean offers window cleaning services for the client at {{site}}. The estimated scope of work is {{estimated_work_time}}.

This proposal covers the agreed window cleaning tasks as a complete service. The work will be carried out with professional tools, window cleaning agents suitable for the surfaces, and according to the agreed schedule.

2. Scope of Work

The proposal includes:

  • washing windows inside and outside when it can be done safely
  • washing, drying and finishing glass surfaces
  • wiping window frames and casings in connection with the window cleaning
  • wiping window sills in connection with the window cleaning
  • light cleaning of Venetian blinds, if agreed
  • required work tools, cleaning agents and basic supplies
  • documentation of work progress and completed working hours
  • final review with the contact person, if the schedule allows

The work will be planned to minimise disruption to normal use of the site.

3. Work to Be Agreed Separately

If work is identified during the project that falls outside the scope defined in this proposal, BetterClean will agree it with the client in writing before starting that part of the work.

Work to be agreed separately may include, for example:

  • windows that cannot be accessed safely or reasonably with standard work equipment
  • work at height requiring a separate lift solution
  • removal of paint, stickers, adhesive residue or hardened dirt requiring special methods
  • unusually heavy post-renovation soiling
